## 一分钟上手

1. 打开网址，你会看到一份示例行程（旧金山 2 天 + 洛杉矶 1 天）
2. 点 **⋯ → 🆕 新建一个行程**，从空白开始
3. 顶部填行程名，比如「美西 10 天」
4. 填这一天的**日期**和**当天出发**时间
5. 点底部 **+ 添加地点**，一个个把要去的地方加进去
6. 每个地点只需要填两件事：**停留多久** 和 **用什么方式过去**

剩下的时间全部自动算：几点出门、路上多久、几点到、几点该走。

## 装到手机上

装完就是一个独立图标，全屏运行，跟原生 App 一样，离线也能打开。

| 手机 | 怎么装 |
| --- | --- |
| iPhone | Safari 打开网址 → 底部**分享**按钮 → 「添加到主屏幕」 |
| Android | Chrome 打开网址 → 右上角菜单 → 「安装应用」或「添加到主屏幕」 |

**自动更新**：以后有新功能，你打开 App（或从后台切回来）时会自动更新，不用重装。

> ⚠️ **装之前先打开你的行程链接**（右上角「👥 邀请 → 复制链接」那条），在那个页面上再「添加到主屏幕」。
>
> 因为**从主屏幕图标打开的 App 有一套自己的存储空间**，读不到你在浏览器里存的行程和 Key。
> 万一装完发现是空的、或者顶上显示「仅本机」，不用重装 —— 打开 **⋯ → 🔗 打开行程链接**，
> 把邀请链接粘一次就接上了（配置也会跟着链接过来）。这事只需要做一次。

## 怎么加一个地点

点底部 **+ 添加地点**，弹窗里：

| 字段 | 说明 |
| --- | --- |
| **搜索地点** | 输入名字（中英文都行），从下拉里选，会自动带回地址和坐标 —— **强烈建议用这个**，手填坐标容易错 |
| **名称** | 显示在卡片上的名字，可以改成你习惯的叫法 |
| **类型** | 🏛️ 景点 / 🍜 吃饭 / 🏨 住宿 / 🏞️ 户外 / 🛍️ 购物 / ✈️ 交通 / 📍 其他。决定图钉颜色，选餐厅时会自动识别成「吃饭」 |
| **地址** | 搜索选中后自动填好 |
| **纬度 / 经度** | 自动填好，一般不用管。没有坐标的地点不会出现在地图上，也算不出路程 |
| **停留（分钟）** | 打算在这儿待多久。**把找停车位、排队、上厕所的时间也算进去** |
| **怎么过来** | 🚕 Uber / 🚗 租车 / 🚌 旅行团 / 🚇 公共交通 / 🚶 步行 / 🚲 骑行。指的是**从上一个地点到这里**用什么方式。前三种走的是同一条路、耗时一样，区别只在你怎么坐上这辆车 —— 分开列是为了让你一眼看出这段该叫车、该自己开、还是跟团 |
| **固定时间** | 有订位或门票时段才填，详见下一节。没有就留空 |
| **营业时间** | 从搜索结果选地点时会**自动填**（来自 OpenStreetMap）。也能自己写，格式如 `Mo-Fr 09:00-17:00`、`24/7`、`Mo-Sa 10:00-22:00; Su 11:00-20:00`。填了之后系统会核对「你到的时候人家开不开门」|
| **备注** | 订位号、停车提示、必点菜、穿什么衣服…… |

> **日期会自动接上**：点「+ 新的一天」时，新一天的日期自动是最后一天的第二天。
> 如果你改了某一天的日期，后面**原本一天接一天连着的**那些天会跟着顺延同样的天数
> （整趟推迟一天时特别省事），手动改过日期的天不受影响。改错了可以撤销。

**每天的第一个地点建议放酒店**，停留填 0。这样「几点出门」算的就是你几点离开酒店。

## 读懂时间轴

时间轴上两种卡片交替出现。

### 地点卡片

```
 ②  🏛️ Golden Gate Bridge 金门大桥      09:19 – 10:54
     停留 1 小时 35 分 · Golden Gate Bridge Welcome Center
     📝 停 Welcome Center 停车场，风大带外套
     [编辑] [↑] [↓] [删除]
```

- **左边圆圈里的数字** = 这是当天第几站
- **右上角** = 几点到、待到几点
- **⠿ 手柄**（数字下面）= 按住可以拖动排序

### 路程卡片

```
 🚕 Uber   19 分钟   8.2 km
 09:00 从「Hotel Zeppelin」出门 → 09:19 到达
 [🧭 导航] [换交通方式]
```

- **几点出门** 就是上一个地点的离开时间
- **19 分钟** 是 Google 给的真实路况耗时；如果带 **「估算」** 小标签，说明这段是按直线距离估的（没配地图 Key，或这段抓取失败）
- **🧭 导航** 一点就唤起 **Google 地图 App** 并直接开始导航，起点终点都填好了。
  出发前记得在手机上装好 Google 地图 App —— 没装的话会打开网页版，在国内打不开
- 去**餐厅**的那一段会**橙色高亮**，按钮变成 **🍜 导航去吃饭**

### 当天总览（时间轴上方）

| 项目 | 含义 |
| --- | --- |
| 🚪 出门 | 今天几点离开第一个地点 |
| 🎯 游玩 | 所有停留时间加起来 |
| 🚗 路上 | 所有路程时间加起来 |
| 📏 里程 | 今天总共跑多少公里 |
| 🍜 吃饭 | 今天安排了几顿 |
| 🏁 结束 | 最后一个地点的离开时间 |

下面还可能出现两种提示：

- **⚠️ 有 N 个预约时间赶不上** —— 往下看标红的段落
- **⏳ 全天有 XX 空档** —— 到得比预约早，可以再塞个点进去
- **🚪 有 N 个地点按营业时间算是关着门的** —— 见下面「营业时间核对」
- **🔄 换个顺序大约能少绕 XX** —— 见下面「绕路提示」

## 订位和门票：固定时间

餐厅订了 12:30、门票是 14:00 那一场 —— 把时间填在地点的**「固定时间」**里，系统会：

**1. 倒推最晚出发时间**

路程卡片上会多一行：

> ⏰ 要赶上 12:30 的安排，最晚 **12:18** 必须出发

**2. 赶不上就标红**

> ❗ 已经晚了 25 分钟：要赶上 12:30 的安排，最晚 12:18 必须出发

同时那个地点会有 **迟到 25 分钟** 的红标签，**后面所有安排一起顺延**。看到这个就往前找：缩短前面的停留、砍掉一个点、或者换个更快的交通方式。

**3. 到早了就提示空档**

> 空档 23 分钟

说明你会提前到、干等 23 分钟。可以在附近加个小点，或者把前一个地点多待一会儿。

## 调整顺序

- **拖拽**：按住卡片左边的 **⠿** 手柄拖动。拖到列表边缘会自动滚动，松手就位
- **按钮**：卡片上的 **↑ ↓**

不管用哪种，路程时间都会自动重算 —— 顺序一变，谁离谁近就全变了。

### 按时间自动排

给某个地点填了**固定时间**、但它排在了不该在的位置（比如 09:30 的早餐排在了 18:30 的晚饭后面），
保存时会**自动把它挪到时间对得上的位置**，并提示你挪到了第几位。

如果一天里有多处顺序颠倒，当天概览下面会出现一条提示：

> 🕐 有 2 处固定时间的先后顺序对不上　[⇅ 按时间重排]

点一下就按时间从早到晚排好。也可以从 **⋯ → ⇅ 按固定时间重排当天** 手动触发。

**没填固定时间的地点会跟着走**：比如你把「博物馆」安排在午饭后面，重排时它还是跟在午饭后面，
不会被打散。这样重排不会破坏你原本的安排意图。

排完不满意？**撤销**（右上角 ↩️）就回去了。

## 营业时间核对

给地点填上营业时间之后，系统会拿**这一天的星期几**和**你到访的时段**去核对，在卡片上标出来：

| 标签 | 意思 |
| --- | --- |
| 🚪 营业中 | 你去的时候正常开门 |
| 🚪 周六不营业 | 那天人家休息 |
| 🚪 10:00 才开门，你 09:23 就到了 | 到早了，会白等 |
| 🚪 17:00 就关门了 | 到的时候已经关了 |
| 🚪 17:00 关门，你排到 18:30 | 后半段是关着门的 |

营业时间**从搜索结果选地点时会自动填**（数据来自 OpenStreetMap）。没自动填上就自己写，
支持这些写法：

```
24/7
Mo-Fr 09:00-17:00
Mo,We,Fr 10:00-18:00
Mo-Fr 09:00-12:00,13:00-18:00      （中午休息）
Mo-Sa 10:00-22:00; Su 11:00-20:00  （周日不一样）
Mo-Fr 09:00-17:00; We off          （周三闭馆）
18:00-02:00                        （跨夜）
```

**看不懂的写法不会乱报警**。像 `sunrise-sunset`、`Apr-Oct 10:00-18:00` 这种，
系统会明说「这种写法暂时看不懂，只当备注存着，不会核对」——
宁可不提醒，也不会因为解析不了就误导你改行程。

> ⚠️ OpenStreetMap 的营业时间**未必是最新的**，尤其是小店和季节性景点。
> 重要的地方（要门票的、特意跑一趟的）出发前还是去官网或 Google 确认一下。

## 绕路提示

如果一天的顺序绕了远路，当天概览下会出现：

> 🔄 换个顺序大约能少绕 25 分钟（估算）　[看看怎么排]

点开是「现在」和「建议」两列对照，改动的地方标蓝。**只有你点「按这个顺序排」才会真的改**，
点「先不改」什么都不动，点「这天不用再提」以后这一天就不再提示。

几条它给自己定的规矩：

- **每天第一个和最后一个不动**（通常是酒店）
- **填了固定时间的地点不动**（订位、门票时段）
- 省得不够多（少于 10 分钟）就不吭声

用的是直线距离估算，不消耗路线额度，所以给的是「大概」。
**你要是有别的考虑 —— 顺路买东西、跟人约了、想避开人多的时段 —— 忽略它就好。**
排完不满意，撤销（右上角 ↩️）就回去了。

## 地图怎么用

默认用的是 **OpenStreetMap**，什么都不用配就有地图。

- **图钉**按类型配色，上面的数字是当天的顺序
- **蓝线**按行程顺序把当天的点连起来，画的是真实路线；拿不到路线时画灰色虚线直连
- **点卡片** → 地图定位到那个点
- **点图钉** → 弹出时间信息，时间轴也滚到对应卡片

**⋯ → 🔄 刷新路程时间**：正常情况下加点、调顺序、换交通方式都会自动重算。这个按钮是手动重来一次用的。

> 路程结果按「起点 + 终点 + 交通方式」缓存在本地，同样的两个点不会重复查询，不用担心额度。

### 想要真实的路程时间

光有地图还不够 —— 路程默认是按**直线距离估算**的（卡片上会标「估算」）。想要按真实路网算：

到 [OpenRouteService](https://openrouteservice.org/dev/#/signup) 用邮箱注册一个免费账号（**不用信用卡**），
申请一个 Standard token，粘到 **⚙️ 设置 → OpenRouteService Key** 里就行。每天 2000 次免费，够用。

配好之后开车、步行、骑行都是真实路网算的距离和时间。两个已知短板：

- **没有实时路况** —— 开车时间偏乐观，洛杉矶这种堵城要自己多留点余量
- **公共交通算不了** —— 公交那一档继续按直线估算，标着「估算」

（如果你有已绑卡的 Google Cloud 账号，也可以在设置里切到 Google 地图，那边有实时路况和公交。
但 Google Cloud 在中国大陆不提供服务，国内办不了。）

## 和朋友一起改

> 需要配好 Firebase 才有这个功能。

### 拉人进来

点 **👥 邀请** → **复制链接** → 发给朋友（微信直接发就行）。

- 朋友**什么都不用配**，链接自带配置，点开就能用
- 让他们进去后在 **⚙️ 设置** 里改个昵称，你才知道谁是谁
- 弹窗顶部会告诉你当前状态：**✅ 已连上** 还是 **⚠️ 还没配 Firebase**

### 用起来是什么感觉

- 谁改了什么，其他人 **0.1 秒左右**就看到
- 右上角显示现在有谁在线
- 有人正在编辑某个地点时，那张卡片会显示 **✏️ 小红 正在改**
- **断网也能继续改**，本地先存着，联网后自动补传

### 会不会互相覆盖

不会。每个地点是独立的一条数据：

- 你改 A 地点、朋友改 B 地点 → 两个都保留
- 你改 A 的名字、朋友同时改 A 的停留时间 → **两个都保留**（保存时只写你真正动过的字段）
- 只有你俩改的是**同一个字段**时，才是后保存的那个生效

## 改错了怎么办

**撤销我最近一次改动**：点右上角 **↩️**，电脑上按 `Ctrl / ⌘ + Z` 也行。

**撤销任意一条**：**⋯ → 🕘 修改记录**，里面按时间倒序列着所有改动 —— 谁改的、什么时候、改了什么，每条后面都有「撤销」按钮。

- 撤销会同步给所有人，不是只在你这边生效
- 撤销本身也会留一条记录，可以再撤回来
- 如果那个地点已经被别人删掉了，撤销按钮会置灰，点了会告诉你原因
- 「只看我的」可以过滤出自己的改动
- 记录保留最近 60 条

误删了一整天、或者不小心「载入示例行程」把东西冲掉了 —— 都能在修改记录里撤回来。

## 设置

**⋯ → ⚙️ 设置（Key / 昵称）**

| 项目 | 说明 |
| --- | --- |
| **我的昵称** | 朋友在头像和修改记录里看到的名字 |
| **地图服务** | OpenStreetMap（默认，免费）或 Google 地图（需已绑卡的账号） |
| **OpenRouteService Key** | 有它才有真实路网的路程时间，邮箱注册免费领 |
| **Google Maps API Key** | 只有选了 Google 地图才需要 |
| **Firebase 配置** | 有它才能多人协作。直接粘贴控制台复制的那段就行，不用管格式 |
| **清除本地配置** | 把这台设备上手填的 Key 清掉 |

Key 只存在你自己的浏览器里。配置怎么申请，见另一份《Maps Key 和 Firebase 怎么配》。

## 常见问题

**路程时间旁边有「估算」小标签？**
说明这段没拿到真实数据 —— 要么没配 OpenRouteService Key，要么这段是公共交通（OpenRouteService 不支持），要么抓取失败。估算是按直线距离乘绕路系数算的，参考价值有限，市区里通常偏乐观。

**改了顺序但时间没变？**
正常情况会自动重算。没变就点 **⋯ → 🔄 刷新路程时间**。

**地图一片空白？**
用 OpenStreetMap 时多半是网络问题（地图瓦片来自 openstreetmap.org），换个网络试试。
用 Google 地图时多半是 Key 的域名白名单没配对。

**换了手机，行程还在吗？**
配了 Firebase 的话，在新手机上打开**同一条链接**就能看到，数据在云端。没配的话数据只在原来那台设备的浏览器里 —— 用「导出 JSON」搬过去。

**清了浏览器缓存会丢吗？**
配了 Firebase 就不会（云端有）。没配的话会丢，建议定期导出备份。

**点「导航」没反应 / 打开的是网页？**
说明手机上没装 Google 地图 App。装上之后再点就会直接进 App 导航了。美国境内 Google 地图最好用，出发前装好。

**能离线用吗？**
能。装到主屏幕后飞行模式也能打开，看的是最后一次同步的内容，改动会等联网后补传。但**地图和搜索需要联网**。

**从桌面图标打开是空的 / 显示「仅本机」？**
主屏幕图标有独立的存储空间，第一次打开读不到浏览器里的数据。**⋯ → 🔗 打开行程链接**，
把邀请链接粘一次即可，行程和配置都会接上，以后再点图标就直接是这份了。

**朋友说打开是空的 / 是别的行程？**
确认他打开的是你从 **👥 邀请** 复制的那条完整链接（带 `?trip=` 那一长串）。手动输网址会开到一份全新的空行程。

## 排行程的一些经验

**停留时间要含「隐形开销」**
景点门口找停车位 15 分钟、排队买票 20 分钟、走回车上 10 分钟 —— 这些都算进停留里，不然一天下来能差出一两个小时。

**餐厅一定填固定时间**
美国热门餐厅基本要订位。填上之后系统会倒推最晚出发时间，比自己心算靠谱。

**先粗排，再看告警**
把想去的点一股脑加进去，然后看顶部提示：出现「⚠️ 赶不上」就砍点或缩短停留；出现「⏳ 空档」就说明这天排松了，可以再加。

**善用「换交通方式」**
市区里停车贵又难找，公共交通或步行常常更快。在路程卡片上点一下就能循环切换，时间立刻重算。

**Uber / 租车 / 旅行团 怎么选**
三者算出来的时间一样（同一条路），选哪个是给你自己看的备忘：市区短途、晚上喝了酒选 Uber；
一整天在外面跑、要去国家公园选租车；跟团那几天选旅行团，省得到时候忘了那天不用自己开。

**每天最后加一站「回酒店」**
停留填 0，这样「🏁 结束」显示的才是你真正回到住处的时间，能看出会不会太晚。

**出发前一天点「复制当天行程」发群里**
同行的人不一定都装了 App，一段文字最省事。
