# US Routine · 美国行程时间轴

一个给自由行用的行程规划工具：**记录「什么时间 · 在什么地方 · 做什么事」，接入 Google Maps 把每天的行程打点连线，并自动算出每一段的时间账**——几点出门、玩多久、路上多久、几点必须去下一个、吃饭那顿怎么过去。

参考「圆周 App」的地图 + 时间轴双栏形态，纯前端，无需后端，数据存在你自己的浏览器里。

![界面](docs/screenshot.png)

## 它替你算什么

每个地点你只填两件事：**停留多久** 和 **用什么方式过去**（开车 / 公交 / 步行 / 骑行）。剩下的自动推：

| 你关心的问题 | 界面上的位置 |
| --- | --- |
| 几点出门 | 每段路程卡片：`09:00 从「酒店」出门 → 09:19 到达` |
| 玩多久 | 地点卡片：`停留 1 小时 35 分`，右上角是 `09:19 – 10:54` |
| 路上多久、多远 | 路程卡片：`🚗 开车 19 分钟 · 8.2 km`（真实值来自 Directions API） |
| 几点要去下一个 | 上一个地点的「离开时间」就是下一段的出门时间；有预约时额外显示 `⏰ 最晚 12:18 必须出发` |
| 吃的地方怎么去 | 餐厅那段路程会橙色高亮，带一个「🍜 导航去吃饭」按钮，直接开 Google 地图导航 |
| 会不会赶不上 | 预约时段赶不上时标红 `❗ 已经晚了 25 分钟`，并顺延后面全部安排 |
| 有没有闲太久 | 到得比预约早会显示 `空档 23 分钟`，提示可以再塞一个点 |

顶部还有当天总览：出门时间、游玩总时长、路上总时长、总里程、吃几顿、几点结束。

## 快速开始

```bash
git clone <this repo> && cd US--routine
python3 -m http.server 8000     # 任意静态服务器都行
# 浏览器打开 http://localhost:8000
```

首次打开会载入一份示例行程（旧金山 2 天 + 洛杉矶 1 天），随便改。

### 接入 Google Maps

没有 Key 也能用：时间轴照常工作，路程按直线距离 × 绕路系数估算，标记为「估算」。
填上 Key 后才有地图打点、连线和真实路况耗时。

1. 到 [Google Cloud Console](https://console.cloud.google.com/google/maps-apis/credentials) 建一个 API Key
2. 启用这三个 API：**Maps JavaScript API**、**Directions API**、**Places API**
3. 点右上角「🔑 API Key」填进去

Key 只存在浏览器 localStorage，不会发到任何服务器。建议在 Console 里给 Key 加 HTTP 引用来源限制（比如 `localhost:8000/*`）。

> 计费提示：Directions 的查询结果按「起点+终点+交通方式」缓存在本地，只有新增地点、改顺序或换交通方式时才会重新请求，日常编辑不会反复烧配额。

## 用法

- **加地点** —— 底部「+ 添加地点」。填了 Key 之后，弹窗顶部的搜索框是 Google Places 自动补全，选中会自动带回名称、地址、经纬度，并猜出类型（餐厅自动归到「吃饭」）。
- **固定时间** —— 餐厅订位、门票时段填在「固定时间」。系统会倒推最晚出发时间，并检查你赶不赶得上。
- **调顺序** —— 卡片上的 ↑ ↓，路程时间会自动重算。
- **换交通方式** —— 路程卡片上的「换交通方式」按钮循环切换 开车 → 公交 → 步行 → 骑行。
- **地图联动** —— 点卡片地图定位到该点，点地图图钉会滚到对应卡片。图钉按类型配色并带顺序编号，按行程顺序连线（有真实路线画真实路线，没有画灰色虚线）。
- **复制当天** —— 一键把当天行程导成文字，可以直接发给同行的人。
- **导入 / 导出** —— JSON 文件，方便备份或多设备同步。

## 代码结构

```
index.html          页面骨架 + 两个弹窗（地点编辑 / API Key）
assets/styles.css   样式
js/util.js          时间换算、距离估算、分类与交通方式配置
js/schedule.js      ★ 时间推算引擎（纯函数，不依赖 DOM，可单测）
js/data.js          示例行程
js/store.js         localStorage 读写 + 路段耗时缓存
js/maps.js          Google Maps 接入：打点、连线、Directions、Places
js/app.js           界面渲染与交互
```

推算规则集中在 `js/schedule.js` 的 `computeDay()`：

```
第 1 个地点： 开始 = 固定时间 ?? 当天出发时间
之后每个地点： 到达 = 上一个地点的离开时间 + 路上耗时
              有固定时间时：早到 → 空档；晚到 → 迟到告警并顺延
              离开 = 开始 + 停留
最晚出发时间 = 本站固定时间 - 路上耗时
```
